## 🌟 Overview

Across India, millions of students across all disciplines (Engineering, Commerce/CA, Humanities, and Pure Sciences) operate under an immense invisible burden. They are taught to measure their self-worth strictly by annual CTCs and competitive percentiles, only to encounter an unforgiving corporate threshold, outdated academic curricula, delayed offer letters, and severe financial anxiety.

**The Merit Mirage** brings these hidden realities to light with interactive visual storytelling, verified 2025–2026 data, emotional depth, and multi-stream analysis.

---

## 🚀 Key Interactive Features

1. **The Curated Facade vs. The 3:00 AM Reality:**  
   An interactive comparison slider contrasting celebratory convocation profiles against late-night private exhaustion.
2. **The Double-Shift Paradox (Structural Flaws):**  
   Highlighting the conflict between 75% mandatory classroom attendance for outdated curricula and late-night self-learning required for real employability.
3. **Cross-Disciplinary Reality Matrix:**  
   Tabbed interactive breakdown covering:
   - **Technology & Engineering (B.Tech / BCA):** Algorithmic screening, 18-month delayed onboardings, junior hiring freezes.
   - **Commerce & CA Aspirants:** 9–13% CA attempt bottlenecks, ₹3,000 articleship stipends, unviable campus pipelines.
   - **Humanities & Liberal Arts:** Societal dismissiveness, multi-year UPSC coaching traps, unpaid internship culture.
   - **Pure Sciences & Research:** The academic treadmill (B.Sc ➔ M.Sc ➔ Ph.D.), stipend disbursement delays, delayed financial autonomy.
4. **The Cumulative Stress Index (Live Simulator):**  
   An interactive psychological tension simulator with real-time heartbeat monitoring, battery reserve calculations, and live stream-of-consciousness narratives.
5. **The Parental Debt Clock:**  
   Socio-economic analysis of education loans, middle-class sacrifices, and the strict 180-day post-graduation repayment moratorium.
6. **Autonomy Under Siege (Gender Dimension):**  
   The dual countdown faced by female students between financial independence and marriage ultimatums.
7. **The Sanctuary of Camaraderie:**  
   The bittersweet dynamic of college friends competing for the same corporate vacancies while offering mutual emotional solace.
8. **The Letters That Were Never Mailed:**  
   A modal-driven collection of unvarnished confessions written by students to their parents and society.
9. **Wall of Solidarity:**  
   An anonymous, real-time message board with localStorage persistence allowing students to leave notes of hope and encouragement.

## 🎨 Design System

- **Aesthetic:** Editorial porcelain design with distinct, tailored background tones per section (Warm Peach, Soft Slate, Ivory, Pale Indigo, Amber, Tender Blush, Sage Mint, Parchment, and Sky Azure).
- **Typography:** Modern, legible typography using `Plus Jakarta Sans` and `JetBrains Mono`.
- **Interactivity:** Pure Vanilla JavaScript without heavy external frameworks for ultra-fast loading and smooth performance.

## 🛠️ Getting Started Locally

Clone the repository and serve the files with any static server:

```bash
git clone https://github.com/AaryanKumar677/Student-Pressure-Life.git
cd Student-Pressure-Life
```

Run using Python's built-in HTTP server:
```bash
python -m http.server 3000
```
Open `http://localhost:3000` in your web browser.
